The physical-layer software stack of the EdgeAI Lab wireless testbed,
implemented in C++: modulation, demodulation, filtering, synchronization,
channel encoding/decoding, and phase-offset and carrier-frequency-offset
correction. Python APIs over the C++ core enable scripted, repeatable
over-the-air experiments, with automated workflows that adapt to
heterogeneous physical-layer hardware. Our group's learning algorithms run
on both lab-scale and building-scale deployments of the testbed.

**Institution:** University of Florida · **Advisor:** Dr. Mingyue Ji
· **Tech:** C++, Python

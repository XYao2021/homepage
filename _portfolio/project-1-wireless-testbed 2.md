The full physical-layer software stack of a real-world wireless testbed,
implemented in C++: modulation, demodulation, filtering, synchronization,
and channel encoding/decoding. Python APIs over the C++ core enable
scripted, repeatable over-the-air experiments across heterogeneous radio
hardware, with automated workflows that adapt to different physical-layer
devices.

**Institution:** University of Florida · **Advisor:** Dr. Mingyue Ji
· **Tech:** C++, Python

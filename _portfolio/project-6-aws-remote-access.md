UnionLabs is an AWS-based platform for remote access and sharing of NextG
and IoT testbeds. It includes a web user interface deployed on AWS,
physical-layer (PHY) code for different hardware including USRP and LoRa,
and a unified Union API that reads and uses the different PHY codes —
automatically connecting them to users' algorithms. An abstraction layer
lets users drive the PHY and Union API with a single command, and
collaborators from different universities apply their learning and
optimization algorithms through UnionLabs, using multiple testbeds at the
same time.

Network optimization for low-power LoRa communication: optimization
objectives derived with Lyapunov functions under real-world constraints, a
system architecture that jointly adapts LoRa PHY parameters, and — built on
the joint-adaptation method — a path discovery and optimization system that
keeps multi-hop communication always live against interference and hardware
outages. Policies are evaluated in simulation and deployed on the EdgeAI
Lab testbed across multiple reinforcement-learning algorithms.

**Institution:** University of Florida · **Advisor:** Dr. Mingyue Ji
· **Tech:** LoRa, Python, RL
